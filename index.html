About Me

I am a Junior Project Engineer at IIT Kharagpur working on AI-driven systems for clinical trial retrieval and eligibility modeling. My work spans model development, evaluation, and deployment, integrating large language models with neural ranking and structured reasoning frameworks.

Beyond core modeling, I have experience building end-to-end systems, including client-server architectures, RESTful inference services, and interactive web interfaces, with an emphasis on reliability, interpretability, and reproducibility.

Earlier in my career, I gained hands-on experience in software development through Android application projects and internships, which built a strong foundation in system design, debugging, and user-focused development.

Work Experience

Junior Project Engineer

IIT Kharagpur — Department of Artificial Intelligence

January 2025 – Present  ·  PI: Dr Koustav Rudra

  • Developed NEUREQ, a two-phase neural re-ranking framework for clinical trial retrieval: an LLM answers ten eligibility questions per patient–trial pair as ternary labels (YES/NO/NA) with natural-language justifications; question ID embeddings, categorical answer embeddings, and Bio_ClinicalBERT-encoded justification embeddings are concatenated per question and fed as a sequence to a BiLSTM with additive attention, whose output score is used to re-rank candidate trials — evaluated on the 2021 and 2022 TREC Clinical Trials Track datasets against a 448,000-trial corpus, achieving statistically significant nDCG@10 improvements of up to 45% over baselines; interpretability is provided via Attention × Gradient saliency for ranking attribution and RouteSAE-based mechanistic analysis of LLM hidden states.
  • Developed TCH_CLF, a separate Longformer-based re-ranking method for clinical trial re-ranking that integrates LLM-generated eligibility reasoning with structured trial attributes via a hybrid classification and ranking objective.
  • Applied prompt engineering and quantization techniques across both NEUREQ and TCH_CLF pipelines to optimise LLM output quality, structured response adherence, and inference efficiency at scale.
  • Gained hands-on experience with large-scale GPU infrastructure including H100 and L40 GPUs and DGX cluster environments, learning job queue management, multi-GPU resource allocation, and diagnosing performance bottlenecks such as KV cache over-allocation and driver-level incompatibilities.
  • Deployed a unified FastAPI inference server hosting both NEUREQ and TCH_CLF, with a Streamlit client interface supporting explainable eligibility scoring, batch evaluation, and audit logging for reproducible research workflows.
  • Collaborated with Microsoft Research India as a Visiting Scholar (remote) on improving a WhatsApp-based medical chatbot (CataractBot) by enhancing its RAG framework for better answer accuracy and hospital-specific response grounding.

Projects

Ongoing Research

NEUREQ: Neural Re-ranking Using Eligibility Question Modeling

A two-phase neural re-ranking framework for clinical trial retrieval that uses LLM-driven eligibility question answering to produce interpretable relevance signals. Structured answers to ten clinically motivated questions are used as features for a lightweight neural re-ranker, improving both effectiveness and transparency.

GitHub Repository ↗

TCH_CLF: Reasoning-Augmented Teacher Classifier

A Longformer-based teacher model for clinical trial relevance modeling that integrates LLM-generated eligibility reasoning with structured trial attributes. The model is trained using a hybrid classification and ranking objective and serves as a strong neural baseline for TREC-style clinical trial re-ranking experiments.

GitHub Repository ↗

Clinical Trial Eligibility Checker

An end-to-end client–server system for clinical trial eligibility assessment, integrating NEUREQ and TCH_CLF models with a FastAPI inference server and a Streamlit-based user interface. The system supports explainable eligibility scoring, batch evaluation, and audit logging for reproducible research workflows.
